# Launches are one record, matched to ads by name and checked by Meta video ID

The TRD proposed a distribution chain (package, confirmation, plan, plan revision, target, registration attempt, effective-dated binding) and refused to trust ad names, requiring Marketing to register every post and ad ID by hand. For seven people running Andromeda-style ad sets with dozens of ads, that registration burden would not be kept up. Instead a Launch is a single record (Post or Ad, with caption and thumbnail, planned → live → ended or cancelled); Ads are matched automatically by the Variant code the system writes into the ad name, and the first matched Ad records the Variant's Meta video ID so any later Ad with the same code but a different video becomes a Mismatched Ad for a person to confirm. Organic Posts are linked by pasting the post link. Effective-dated bindings are unnecessary because a Live Variant's file never changes.
