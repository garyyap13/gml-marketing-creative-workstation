# Creative Codes carry no meaning beyond brand and sequence

A Creative Code is printed into Meta ad names forever, but labels such as Narrative Style are chosen after the code is issued and can change. So a code holds only the brand prefix and a sequence number (`GML-0007`, Variant `GML-0007-B`); readable labels are appended after the code in the ad names the system generates. The older brand-type-number codes (`GML-TESTI-0007`) remain valid as Legacy Codes so past ads still match.

We also rejected the TRD's flat `CR-000123` code per variant: it is equally meaning-free, but it hides which Creative a variant belongs to, whereas `GML-0007-A` and `GML-0007-B` show in Ads Manager that they are two cuts of one Creative, which the Combination view relies on.
